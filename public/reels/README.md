# Reel media for Partner Player

Put files here so Next can serve them at `/reels/...`:

- `ui.mp4` → `/reels/ui.mp4` (glass device UI recording)
- `plate.mp4` → `/reels/plate.mp4` (optional local plate)

Remotion Studio uses a **different** folder: `reels/public/`.
Copy media into both if you use Studio and this Partner page.
